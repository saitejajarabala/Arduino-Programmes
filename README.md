# LED_Light

## Purpose
Controls an LED using two pushbuttons. The LED turns on when both buttons are pressed (logic LOW).

## Dependencies
- Arduino core libraries

## Usage
1. Connect an LED to digital pin 10 and pushbuttons to pins 8 and 9.
2. Compile and upload `LED_Light.ino` using the Arduino IDE.
3. Press both buttons to light the LED.

## Example
When both buttons read LOW, the LED connected to pin 10 is set HIGH.
